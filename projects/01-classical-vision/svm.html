Homework 01 · Classical Vision

Part C — Multiclass SVM and hinge loss

Implement a vectorized margin loss, derive its gradient, and compare learned class templates.

Duration: Two sessions × 1h30 Mode: Individual Format: One self-contained Jupyter notebook Deliverable: Completed notebook with passing checks, plots, and analysis

The challenge

The Softmax classifier asks for calibrated relative probabilities. A multiclass linear SVM asks a different question: is the correct score larger than every incorrect score by a safety margin?

\[L_i=\sum_{j\ne y_i}\max(0, s_j-s_{y_i}+\Delta).\]

You will implement this hinge loss without loops, derive the gradient from active margin violations, verify it numerically, and optimize the same linear score function used by Softmax.

What you implement

  1. Reproducible small-random parameter initialization.
  2. Fully vectorized multiclass hinge loss with L2 regularization.
  3. Analytical gradients obtained from the active-margin mask.
  4. One in-place SGD update—the backward step that changes the parameters.

The notebook supplies prediction, mini-batch training, numerical gradient checking, the learning-rate/L2 grid search, final evaluation, and visualization of the ten learned weight templates.

Submission standard

Submit the notebook after restarting and running all cells. It must contain all green checks, the numerical-gradient report, loss curves, validation grid, final accuracies, class templates, and completed reflection prompts.
