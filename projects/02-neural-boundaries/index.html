Project 02 · Neural Decision Boundaries

From one hidden layer to a modular NumPy network

Discover how activation and depth reshape a nonlinear classification boundary.

Duration: Two sessions × 1h30 Mode: Individual Format: One self-contained Jupyter notebook Deliverable: Passing checks, 3×3 experiment, and evidence-based conclusions

The challenge

Concentric circles defeat a linear classifier but are easy for a suitable neural network. You will first build one hidden layer explicitly, then turn its components into a tiny modular framework and compare nine networks:

1 hidden layer 3 hidden layers 5 hidden layers
Sigmoid model 1 model 2 model 3
Tanh model 4 model 5 model 6
ReLU model 7 model 8 model 9

For every model, you will record training time, validation accuracy, and the learned decision region. The objective is not to declare one activation universally best; it is to explain what happened under one controlled experimental protocol.

What you implement

  1. A one-hidden-layer network with initialization, cached forward pass, and prediction.
  2. Numerically stable binary cross-entropy.
  3. Modular Sigmoid, Tanh, and ReLU forward transformations.
  4. A reusable Linear layer with initialization and a cached forward pass.
  5. Nine architectures expressed only as lists of layers.

The notebook provides data generation, plotting, every backward operation, parameter updates, Sequential, the training harness, experiment table, and the final 3×3 decision-region visualization. Backpropagation and optimization are deliberately treated as infrastructure; we will open that black box in later chapters.

Two-session rhythm

Session Work Checkpoint

Experimental discipline

All nine models use the same data split, width, learning rate, number of epochs, and reproducible initialization policy. Only activation and depth change. Compare validation—not test—performance while developing the models.

Important

Visible checks are learning aids, not secure grading. Restart the kernel and run every cell before submission. A result without the code and reasoning that produced it is incomplete.
